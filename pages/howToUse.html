How to Use ExcaliburFX

Install the extension, then use this guide to explore its curve, expression, color, command-chain and sound tools. For help inside the extension, open the Settings tab and select the help section from the ExcaliburFX logo.

Install the extension

  1. Download the recommended ExcaliburFX Installer (.exe), or download the extension (.zxp) and install it with a ZXP installer.
  2. Run the .exe installer, or use your ZXP installer to install the .zxp file.
  3. Open the application where you use ExcaliburFX and open the extension.

Shape keyframes with curves

Use Presets Curves to save and apply custom Bézier curves to keyframes. You can also copy and paste graph data across timeline selections. Live Curves applies a curve directly to keyframes.

Work with layers and expressions

Use the Work tab to edit layers on your timeline. The Expression Library includes more than 80 built-in expressions to apply to layers, and lets you save your own expressions.

Manage presets and plugins

Save frequently used presets and plugins in the library for quicker access in future projects.

Build effects and command chains

Use the Effects Builder for additional effects tools. In Command Chain, combine blocks and apply the chain to layers; the result is rendered and placed on the timeline. Save command chains as presets to reuse them.

Use color and sound tools

In the Colors tab, choose a color or preset, apply it to a layer, or copy its HEX value. In the SFX Library, preview and add sound effects, import your own, and adjust the default sound effects. SFX Effects provides effect, fade-in, fade-out and wave controls.

Customize the extension

Open Settings to change themes, disable menus you do not use and organize projects. The built-in help is also available from the ExcaliburFX logo in this tab.
